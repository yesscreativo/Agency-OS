# Agency OS

## Problema
La operación de agencias está distribuida entre múltiples herramientas.

## Solución
Una plataforma única para CRM, Operación, RRHH, Analytics e IA.

## Beneficios
- Menos herramientas
- Mayor trazabilidad
- Control de tiempos
- KPIs en tiempo real
- Portal del cliente
- IA como copiloto operativo

## Stack
Next.js + Supabase + n8n + OpenAI
